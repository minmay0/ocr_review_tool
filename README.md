# 🔍 OCR 검수 툴 (ocr_review_tool.html)

OCR(광학 문자 인식) 결과물을 빠르게 검수하기 위한 **브라우저 기반 단일 HTML 툴**입니다.  
별도 설치 없이 파일을 더블클릭하거나 공유 링크를 열면 바로 사용할 수 있습니다.

## 주요 기능

|------|------|

## 사용 방법

### Step 1 — 파일 열기

```
ocr_review_tool.html 파일을 브라우저(Chrome 권장)로 열기
→ 파일을 더블클릭하거나, GitHub Pages 링크 접속
```

### Step 2 — 이미지 소스 선택

**방법 A: ZIP 파일 업로드** → 권장
- 이미지들을 ZIP으로 묶어서 통째로 업로드
- 압축 해제 없이 내부 이미지를 직접 읽음

**방법 B: 폴더 선택**
- 이미지가 담긴 폴더 전체를 선택
- `.jpg`, `.jpeg`, `.png`, `.gif`, `.bmp`, `.webp` 지원

### Step 3 — 엑셀 파일 업로드

- OCR 결과가 담긴 엑셀 파일 선택
- 자동으로 열 이름을 분석해서 **파일명 열**과 **텍스트(정답) 열**을 추측
- 추측이 틀렸다면 드롭다운에서 직접 선택

### Step 4 — 검수 시작

- `검수 시작 →` 버튼 클릭
- 왼쪽: 이미지 / 오른쪽: 정답 텍스트 + 판정 버튼

### Step 5 — 판정

| 버튼 | 의미 | 단축키 |
|------|------|--------|
| ✅ 일치 | OCR 결과가 정답과 일치 | `O` |
| ❌ 불일치 | OCR 결과가 정답과 다름 | `X` |
| ⭕ 건너뛰기 | 판단 보류 | `S` |

판정 후 자동으로 다음 항목으로 이동합니다.

## 엑셀 파일 형식

엑셀 파일은 아래와 같은 구조여야 합니다. (헤더 이름은 자유롭게 설정 가능)

| filename | text |
|----------|------|
| img_001.jpg | 안녕하세요 |
| img_002.png | 반갑습니다 |
| img_003.jpg | 한글도 |

> **팁**: 헤더에 `file`, `name`, `파일`, `이름` 중 하나가 포함되면 파일명 열로 자동 인식됩니다.  
> `text`, `label`, `글자`, `텍스트`, `정답` 중 하나가 포함되면 텍스트 열로 자동 인식됩니다.

## 키보드 단축키

| 키 | 동작 |
|----|------|
| `O` | ✅ 일치 판정 후 다음으로 이동 |

| `S` | ⭕ 건너뛰기 후 다음으로 이동 |

> 메모 입력 중에는 단축키가 비활성화됩니다.

## 코드 구조 설명

> 코드를 수정하거나 기능을 추가하고 싶은 분들을 위한 설명입니다.

```
ocr_review_tool.html  (단일 파일, 외부 의존성 없음)
│
├── <style>         CSS 스타일 (다크 테마, 레이아웃)
├── <body>          HTML 구조
│   ├── #setup      설정 화면 (파일 업로드 UI)
│   └── #reviewer   검수 화면 (이미지 + 판정 패널)
└── <script>        JavaScript 로직
    ├── loadFolder()   이미지 폴더 로드 → imageMap에 objectURL 저장
    ├── loadZip()      ZIP 파일 파싱 → zipEntries에 lazy 저장
    ├── loadExcel()    엑셀 파싱 → rows[] 배열 생성
    ├── startReview()  검수 시작, results[] 초기화
    ├── render()       현재 항목을 화면에 표시 (이미지 lazy load 포함)
    ├── judge(val)     판정 기록 후 다음으로 이동
    ├── move(dir)      이전/다음 이동
    └── exportResult() 결과를 xlsx로 다운로드
```

### 핵심 상태 변수

```javascript
let imageMap   = {};  // { 파일명: ObjectURL } 캐시
let zipEntries = {};  // { 파일명: JSZip Entry } - 필요할 때 blob 변환
let rows       = [];  // 엑셀에서 파싱한 원본 데이터
let results    = [];  // 판정 결과가 추가된 rows (result, memo 필드 포함)
let cur        = 0;   // 현재 보고 있는 인덱스
```

### 이미지 매칭 방식

```javascript
function normalizeKey(name) {
  // 경로에서 파일명만 추출하고 소문자로 변환
  // 예: "images/subfolder/IMG_001.JPG" → "img_001.jpg"
  return name.split(/[\\/]/).pop().toLowerCase().trim();
}
```
ZIP 내부 경로와 엑셀의 파일명이 달라도 **파일명 기준**으로 매칭합니다.

### 외부 라이브러리

| 라이브러리 | 버전 | 용도 |
|-----------|------|------|
| [SheetJS (xlsx)](https://sheetjs.com/) | 0.18.5 | 엑셀 파일 읽기/쓰기 |
| [JSZip](https://stuk.github.io/jszip/) | 3.10.1 | ZIP 파일 내부 직접 접근 |

CDN으로 로드되므로 **인터넷 연결이 필요**합니다. 오프라인 환경이라면 두 라이브러리를 로컬에 다운로드해서 `src` 경로를 변경하세요.

## 자주 묻는 질문 (FAQ)

**Q. 이미지가 표시되지 않아요.**  
A. 엑셀의 파일명(확장자 포함)과 실제 이미지 파일명이 일치하는지 확인하세요. 대소문자는 자동으로 맞춰줍니다.

**Q. ZIP 파일 안에 하위 폴더가 있어도 되나요?**  
A. 네. 하위 폴더 구조는 무시하고 파일명만으로 매칭합니다.

**Q. 중간에 창을 닫으면 데이터가 사라지나요?**  
A. 네, 현재 버전은 브라우저 메모리에만 저장됩니다. 중간에 자주 `📥 결과 엑셀 저장`을 눌러 백업하세요.

**Q. CSV 파일도 되나요?**  
A. 네, `.csv` 파일도 지원합니다.

**Q. 지원하는 이미지 형식은?**  
A. `.jpg`, `.jpeg`, `.png`, `.gif`, `.bmp`, `.webp` 를 지원합니다.
